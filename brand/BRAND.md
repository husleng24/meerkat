## 一、为什么换

| v2 的问题 | 实测 |
|---|---|
| 头部浅色面与纸白底 **1.08:1** | 几乎同明度，轮廓全靠深棕线撑着 |
| 全身像在 32px 只剩一条深色竖条 | 内容框 604×1002，宽高比 0.60 |
| 暖棕三色与 Lumen 的靛蓝/青无关 | 侧栏 32px 的暖色贴纸像另一个产品 |

v3 的答案：**只留头，压成两色（奶油 + 墨），放进靛蓝方块**。
形状不变——轮廓和眼罩都是从原插画上描下来的，所以它还是同一只狐獴。

## 二、标志规格

| 项 | 值 |
|---|---|
| 画布 / 圆角 | 512 / 115（22.5%） |
| 底 | 靛蓝渐变 `#5B52EA → #3B33B4`，左上角一层极淡青光（`#7DD3FC` 30%） |
| 头 | `#F7F8FB`（对底 5.92:1） |
| 眼罩 | `#0B1220`（对头 17.63:1） |
| 构图 | 头宽占画布 89%，胸腔从底边出血，不做底座 |
| 路径 | 主标 `icon-meerkat.svg`；小尺寸字形 `icon-meerkat-glyph.svg` |

**暖版**（`concepts/meerkat-mark-warm.svg`）留着但不用：奶油 `#F1E7DC` + 棕墨 `#2A1D16`，
保住了插画的温度，代价是与靛蓝底的分离弱一档（5.15:1）。要换回来是一行改色的事。

## 三、尺寸规则（实测过，不是推测）

| 尺寸 | 用哪个 | 说明 |
|---|---|---|
| ≥ 32px | `icon-meerkat-{1024…32}.png` | 主标直接缩，32px 时眼罩与鼻子仍可辨 |
| 24 / 22 / 16 | `icon-meerkat-{24,22,16}.png` | **小尺寸字形**：头 + 一道眼罩，三形状封顶 |
| 托盘 | `icon-meerkat-head-16.png` | 托盘优先取 16px 专用字形（见 `src/main/scheduler.ts`） |
| 托盘 32 | `icon-meerkat-head-32.png` | 主标，供更宽的托盘位用 |

**这条是硬规则**：不要用 512 主标缩到 ≤24px。实测那一档会糊成一团
（`concepts/compare.png` 最右列是 16px 放大 8 倍的真值）。

小尺寸字形为什么去掉眼睛和鼻子：16px 下它们会并进眼罩里变成灰噪声，
只留「浅色头 + 一道深色罩」反而读得出来。

## 四、色

| 角色 | 值 | 用途 |
|---|---|---|
| Ink | `#0B1220` | 眼罩、正文 |
| Paper | `#F7F8FB` | 头、画布 |
| Indigo | `#5B52EA → #3B33B4` | 图标底（Lumen accent 家族） |

界面用色以 `docs/VISUAL-WORLD.md` 为准。v2 的暖棕三色（`#3A2921 / #F1E7DC / #B78D5A`）
降级为**插图专用**：只在启动页、关于页这类"出现整只狐獴"的地方使用。

> `BRAND.md` v2 曾写"这三个色就是品牌色"，与 `VISUAL-WORLD.md` 的冷白界面冲突。
> v3 起以本条为准：**图标用靛蓝 + 墨 + 纸白，插图可以用暖棕。**

## 六、待办

1. **字标**：现在组合标用系统 PingFang，不是设计过的字。要么手工调字距，要么买一套。
2. **托盘改模板图**：现在托盘加载的是彩色 chip，在深色菜单栏里是一块彩色方块（不是系统模板图）。
   要做一版单色 `trayTemplate` 并调用 `setTemplateImage(true)`，深浅色由系统着色。
3. **深色底适配**：主标本身是深底，放在深色桌面/深色标题栏时边缘会融。需要一版加描边的。
4. **关于页**：整只狐獴（`logo-meerkat.png`）还没在任何界面出现过，插图能力浪费了。
