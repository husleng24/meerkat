# 标志方向：从狐獴到一条缝

> 2026-11-01 · **提案，未落地**。没有改 `BRAND.md`、没有动 `src/`。
> 依据：`brand/master.png` 实测、`docs/VISUAL-WORLD.md`、512/64/32/16px 与 22px 托盘的真实像素渲染。
>
> 说明：Pinterest 在这个环境里连不上（`curl` 20s 超时，`web_fetch` 同样失败），
> 所以没有逐张翻图。下面的判断全部来自**这个 App 必须出现的尺寸与场景**，
> 每一条都能在 `compare-simple.png` 里找到对应的像素。

## 结论

**不画动物。主标是一条缝**：靛墨方块上的一道纸白缝隙，除此之外没有第二笔。
名字交给字标（`Meerkat` + `替你盯着`），托盘用镂空版并单独做小尺寸补偿。

备选是字母标 `m`——更保险、更"有名字"，但也更平庸。

## 一、为什么狐獴头这一稿不够

| # | 问题 | 证据 |
|---|---|---|
| 1 | 头部浅色面与纸白底 **1.08:1** | 几乎同明度，轮廓全靠深棕线撑着 |
| 2 | 全身像在 32px 只剩一条深色竖条 | 宽高比 0.60，狐獴本来就瘦高 |
| 3 | 头像版 16px 也糊 | `compare.png` 第 3 行最右 |
| 4 | 暖棕三色与 Lumen 的靛蓝/青无关 | 侧栏里那张贴纸和界面像两个产品 |

它仍然是一个好用的**角色**（启动页、关于页都适合），只是不适合当标志。

## 二、去掉动物之后，用什么筛

1. **16px 能活**——不是"缩下去还能看"，是"缩下去还是它"。
2. **一个形**——第二个元素必须能被删掉而不影响识别。
3. **两色**——彩色到单色的降级路径只有一条。
4. **不靠故事也成立**——讲一遍才懂的图形，在图标格子里没人听。

## 三、试过并否掉的

| 试的形 | 结果 |
|---|---|
| 两片眼罩（把狐獴的眼罩抽出来） | 中间一挨就成**蝴蝶结 / 无限符号** |
| 潜望镜（竖杆 + 横臂） | 像**台灯**，也像表格里的 `┌` |
| 楔形（宽进窄出，表示收敛） | 就是**播放键** |
| 对称眼 + 瞳孔 | 太像通用"眼睛"图标，且与"读"无关 |
| 竖缝 | 缩到 64px 像**一粒米** |
| 日（方框 + 一横） | 一眼被读成**日历**，而这不是日历 App |
| 三条源收成一条 | 像**流程图**，不像标志 |
| 半阖眼（上缘平、下缘深） | 读成**笑脸** |
| 单片横缝 | ✅ 留下 |
| 字母 `m` | ✅ 留下 |

这张表是这个提案里最有用的部分：**否掉的每一条都有具体原因，不是口味**。

## 四、留下的两条

| | 一条缝 | `m` |
|---|---|---|
| 512 | 一个形，两色，留白极大 | 干净，但只是"一个字母" |
| 64 / 32 | 仍然是它 | 仍然是它 |
| 16 | 需要重画（见下） | 天生成立 |
| 托盘 22px | 需要补偿后才清楚 | 天生成立 |
| 语义 | 门缝里的光 / 一只半阖的眼 / 一条地平线 | 只有名字 |
| 风险 | 空——不配字标就什么都不是 | 平庸——任何 m 开头的产品都能用 |

**建议选缝**，理由是它符合这个产品的性格：早上五分钟、不喧哗、把 35 个源压成一份。
一个形就能说完的事，不必画一只动物。

## 五、规格

| 项 | 值 |
|---|---|
| 画布 / 圆角 | 512 / 115（22.5%） |
| 底 | `#0B1220`（界面的 ink，不引入新色） |
| 缝 | `#F7F8FB`；330×116，中心略高于画布中线（y=252） |
| 路径 | `M91 252C158 194 354 194 421 252C354 310 158 310 91 252Z` |
| 浅色版 | 纸白底 + 墨缝（`slit-mark-light.svg`），用于打印与文档 |

**尺寸规则**

| 尺寸 | 用什么 |
|---|---|
| 512 / 256 / 128 / 64 / 32 | `slit-mark.svg` 直接缩 |
| 22 / 16（托盘） | `slit-tray.svg`：镂空单色，**缝高从 22.7% 提到 25%** 做光学补偿 |
| 16（应用图标） | 单独画，不要缩 512 |

托盘这条是实测出来的：缝高掉到 21% 时，16px 会退化成一条实心胶囊；
提到 25% 后，"方块里一道亮缝"的形状还在（见 `compare-simple.png` 托盘条）。
这就是 `BRAND.md` 里"≤32px 换头肩版"的同一条规律，换了对象。

## 六、需要裁决

1. **缝，还是 m？** 缝更好看也更"克制"，m 更稳妥也更"有名字"。
2. **文档冲突**：`BRAND.md` 说"这三个色就是品牌色"（暖棕），
   `VISUAL-WORLD.md` 已经把界面改成冷白 + 靛蓝/青。这两份现在互相打脸，
   标志落地前必须只留一份说法。

## 七、没做的

- 16px 专用稿、ICO/ICNS、深色底适配：等方向定了再画。
- 字标：现在用的是系统 PingFang，真正的字标需要一套有授权的无衬线，或手工调字距。
- 没有动 `BRAND.md`、`master.png`、`src/` 的任何一行。
