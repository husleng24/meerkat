# 界面重做的三个方向（2026-10-31）

旧界面"不够明亮"的根因不是颜色选得不好，而是**底色本身就是中灰暖**（`#F6F1E7` / `#F1E7DC`），
再叠一层 60% 白的卡片，整页发灰。三稿都把底提到近白，差别在"用什么制造惊艳"。

三份渲染稿是独立的 HTML（不依赖应用代码），可以直接用浏览器打开对比：

| 文件 | 方向 | 靠什么 |
|---|---|---|
| `A-morning-paper.html` | 晨光报纸 | **排版**：报头、双线、细线分隔、17px 速览 |
| `B-lumen.html` | 清透 Lumen | **光**：靛蓝/青径向渐变 + 悬浮卡片 |
| `C-vermilion.html` | 朱砂 | **色块**：通栏红报头 + 字号对撞 |

## 最终选择：A 的骨架 + B 的强调色

`FINAL-*.png` 是落地后的真实界面（渲染层截图）。

理由：

- **A 的报纸骨架**承担"早上读得下去"——细线与留白比卡片墙安静，五分钟后眼睛不累
- **B 的靛蓝**承担"跟别的简报工具不一样"——琥珀在暖底上饱和度不足，靛蓝在近白底上 6.1:1
- **C 的红色被否**：红在本产品里已经是"失效源"的语义色，拿来做报头会稀释警报
