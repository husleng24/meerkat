# 视觉世界：Lumen（清透）

> 2026-10-31 重做，第二版。第一版是"晨光报纸"（暖白 + 细线），看过之后改为现在这版：
> **冷白底 + 靛蓝/青的极淡光晕 + 悬浮卡片**。
>
> 两版共同解决的是同一个根因：旧界面的底色本身是中灰暖（`#F6F1E7` / `#F1E7DC`），
> 再叠 60% 白卡片，整页发灰。**"明亮"的前提是画布必须近白。**

## 一句话

一块冷白的桌面，简报卡片浮在上面，光从左上角斜进来。

|---|---|---|---|

`ink-3` 的原始候选是 `#93A0B4`，只有 2.8:1——它承载 11px 的源名与日期，小字更需要对比度，
所以压到 `#6D7889`。

## 光

只出现在两处，都不做玻璃拟态：

1. **页面顶部** `.lumen-glow`：两团极淡径向（靛蓝 24% + 青 20%），高度 460px，
   上边缘外扩 160px 让渐变从视口外开始，避免出现硬边。
2. **今日一句卡片内**：右下角一团靛蓝辉光，作为整页唯一的暗面落点。

## 卡片

世界的唯一悬浮物。高度只声明一次：

```css
.card { background:#fff; border:1px solid #E6EAF2; border-radius:16px }
.card-hover:hover { border-color:#C9D0FF; box-shadow:0 12px 30px -22px rgba(79,70,229,.6); transform:translateY(-1px) }
```

**边框定轮廓，阴影定层次，两者不同时用于一个元素**——否则就是"幽灵卡片"。

## 版式规则

1. 标题行：`今日简报` 22px/700 + 日期副行 + 右侧胶囊「34 源 · 24 条」
2. 三句话卡：单个卡片内三条，编号 17px/800 靛蓝，条目间 1px 细线
3. 板块：13px 粗标题 + 灰色计数，卡片之间 10px 间距
4. 卡片：标题 15–15.5px，正文 13.8–14px / 1.75，行宽 66ch
5. 今日一句：深色渐变卡 + 靛蓝辉光，白字 15.5px/600
6. 留白：板块之间 24px，卡片之间 10px
7. 侧栏：只有三级字号——分区标签 10px/600、行与可点项 13px、数字与元信息 11px；
   所有文字共用同一条左边缘（26px），数字右对齐到同一列（189px）。
   同一栏里出现 10.5 / 11.5 / 12.5 这种"半档"字号就是版式开始失控的信号。

## 动效

只有一处：条目自下淡入 10px，错峰 40ms，`cubic-bezier(.16,1,.3,1)`，500ms。
`prefers-reduced-motion` 下关闭。

悬停有 1px 上浮与一层极淡投影——这是"卡片"这个世界的物理直觉，不算额外的动效。

## 浏览器自带件

- 选中色 `#C7D2FE`
- 滚动条 10px，拇指 `#D7DCE6`，3px 画布内边距
- 焦点环 2px 靛蓝 + 2px offset

## 明确不做

- ❌ 渐变文字
- ❌ 玻璃拟态 / 背景模糊（光晕是径向渐变，不是 blur）
- ❌ 卡片里套卡片
- ❌ 标题上方的 kicker / eyebrow
- ❌ 彩色左边条（选中态用靛蓝描边 + 浅底）
- ❌ 每条都长一样（每个板块头条略大）

## 三个方向与最终选择

`design-comps/` 保留了当时的三稿：

| | 靠什么惊艳 | 结果 |
|---|---|---|
| A 晨光报纸 | 排版：报头、双线、细线分隔 | 做过一版，看过之后改为 B |
| **B 清透 Lumen** | **光：靛蓝/青渐变 + 悬浮卡片** | **采用** |
| C 朱砂 | 色块：通栏红报头 | 否——红已是"失效"的语义色 |

A 与 B 是同一份内容、两种气质：A 更像"早上的一份报纸"，B 更像"一个现代工具"。
最终选 B。
