# 视觉世界：晨光报纸

> 2026-10-31 重做。上一版是"暖米色卡片墙"，早读时整页发灰。
> 这一版把底提到近白，用**报纸的版式**承担节奏，用**靛蓝**承担强调。

## 一句话

像一份早上摊在桌上的报纸：报头是日期，正文是细线分隔的条目，
唯一的重色块留在最后那句判断上。

## 为什么换

| 旧 | 问题 |
|---|---|
| 底色 `#F6F1E7` / `#F1E7DC` | 本身就是中灰暖，再叠一层 60% 白卡片，整页发灰 |
| 每条一张卡片 + 边框 + 阴影 | 24 条 = 24 个盒子，视觉噪声盖过内容 |
| 琥珀 `#B78D5A` 当强调色 | 暖底上饱和度不足，且与插画狐獴撞色 |
| 板块标题带 ①②③ 圈码 | 与正文里的编号重复，且圈码在小字号下发糊 |

## 令牌

| 名称 | 值 | 用途 | 对比度（on `#FCFBF8`） |
|---|---|---|---|
| `paper` | `#FCFBF8` | 画布 | — |
| `ink` | `#14110F` | 主文字、报头、今日一句底 | 18.2:1 |
| `ink-2` | `#5B544E` | 次级文字 | 7.2:1 |
| `ink-3` | `#746C64` | 元信息（源名、日期、计数） | **5.0:1** |
| `rule` | `#E9E3DA` | 分隔线 | — |
| `cream` | `#F2EDE6` | 浅色面（输入框底、悬停） | — |
| `accent` | `#4F46E5` | 强调：编号、板块计数、选中、焦点 | 6.1:1 |
| `accent-soft` | `#EEF0FF` | 强调浅底（选中行、激活导航） | — |
| `alert` | `#C0392B` | 唯一警报色：失效源 | 5.3:1 |

`ink-3` 从 `#8F877E` 调到 `#746C64` 是必须的：前者只有 3.42:1，
而它承载的是 11px 的源名与日期——小字更需要对比度。

## 版式规则

1. **报头**：日期是整页最大的东西（34px / 800 字重 / -0.04em），右侧是条数与源数。
   下面一粗一细两条线（`masthead-rule`），是报纸的招牌动作。
2. **三句话速览**：17px / 1.68，编号用靛蓝 tabular 数字，条目间细线分隔。
3. **板块**：2px 黑线 + 板块名 + 靛蓝计数。线是分界线，不是装饰。
4. **条目**：没有卡片、没有边框、没有序号。标题 16px / 700，正文 14px / 1.78，
   行宽上限 68ch。每个板块的**头条**放大到 18.5px——报纸的 lead story。
5. **今日一句**：唯一的深色块，白字，靛蓝小标签。整页到这里收住。
6. **留白**：板块之间 36px，条目之间 15–20px，标题上方永远比下方多。

## 动效

只有一处：条目自下淡入 8px，错峰 40ms，`cubic-bezier(.16,1,.3,1)`，500ms。
`prefers-reduced-motion` 下完全关闭。

不做：悬停抬升、发光、视差。早上读的是内容，界面不该跟着动。

## 浏览器自带件

这三样是"有人设计过"最便宜的证据，全部重设：

- 选中色 `#DCDFFE`
- 滚动条 10px，拇指 `#DDD6CC`，带 3px 画布内边距
- 焦点环 2px 靛蓝 + 2px offset

## 明确不做

- ❌ 渐变文字
- ❌ 玻璃拟态 / 模糊装饰
- ❌ 卡片里套卡片
- ❌ 标题上方的 kicker / eyebrow
- ❌ 彩色左边条（选中态用小圆点）
- ❌ 每条都长一样（头条必须更大）

## 三个方向与选择

`design-comps/` 里保留了当时的三稿：

| | 靠什么惊艳 | 为什么没选 |
|---|---|---|
| **A 晨光报纸** | 排版 | 选了它的骨架 |
| **B 清透 Lumen** | 光（靛蓝/青渐变） | 卡片墙太像通用 AI 产品 |
| **C 朱砂** | 色块（通栏红） | 红已是"失效"的语义色，冲突 |

最终：**A 的骨架 + B 的强调色**。报纸的节奏负责"早上读得下去"，
靛蓝负责"跟别的简报工具不一样"。
