# Trust layer

这一层给“这条内容有多可信”一个**可解释但不冒充事实核查**的提示。

## 三个标签

`ItemCard` 底部会显示：

```text
事实 / 推断 / 传闻
```

规则按措辞匹配：

- **传闻**：reportedly / allegedly / 未确认 / 据称 / 传闻…
- **推断**：may / could / likely / 预计 / 可能 / 或许…
- **事实**：没有命中前两类

「事实」只表示“这是一条有来源的报道”，**不表示 Meerkat 已独立验证**。标签会误判，所以每条仍保留来源链接和「来源依据」。

## 来源多样性

简报页顶部显示：

```text
来源 9 · TechCrunch AI 32%
```

- 来源数按 trace 的 `sourceName` 去重；
- 最大单源占比 ≥ 60% 标黄「集中」；
- 这是提示，不是封禁：单一源有时是合理的。

## 无依据率

```text
无依据 0/19 · 0%
```

定义很窄，必须明确：

> **没有 trace 来源证据的条目数 / 总条目数。**

它衡量的是“这条内容有没有来源依据”，不是“这句话在语义上是否真实”。旧简报没有 trace 时显示「旧简报无来源证据」，不伪造 0%。

## 为什么先这么做

- 可解释：每个数字都能回到底层条目；
- 可重复：同一标题永远得到同一个标签；
- 不烧模型：不需要为每条内容调用 LLM；
- 不装权威：不把启发式叫“事实核查”。

## 下一步

- 固定评测集：无依据断言率、链接准确率、重复率；
- 事实 / 推断 / 传闻的人工校正；
- 来源平衡建议（补哪些类型的源）；
- 模型成稿的 claim-level 引用覆盖率。
