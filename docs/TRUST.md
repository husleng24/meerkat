# Trust layer

这一层给“这条内容有多可信”一个**可解释但不冒充事实核查**的提示。

## 三个标签

`ItemCard` 底部会显示：

```text
事实 / 推断 / 传闻
```

规则按措辞匹配：

- **传闻**：reportedly / allegedly / 未确认 / 据称 / 传闻…
- **推断**：may / could / likely / 预计 / 可能 / 或许…
- **事实**：没有命中前两类

「事实」只表示“这是一条有来源的报道”，**不表示 Meerkat 已独立验证**。标签会误判，所以每条仍保留来源链接和「来源依据」。

## 来源多样性

简报页顶部显示：

```text
来源 9 · TechCrunch AI 32%
```

- 来源数按 trace 的 `sourceName` 去重；
- 最大单源占比 ≥ 60% 标黄「集中」；
- 这是提示，不是封禁：单一源有时是合理的。

## 无依据率

```text
无依据 0/19 · 0%
```

定义很窄，必须明确：

> **没有 trace 来源证据的条目数 / 总条目数。**

它衡量的是“这条内容有没有来源依据”，不是“这句话在语义上是否真实”。旧简报没有 trace 时显示「旧简报无来源证据」，不伪造 0%。

## 句子级引用覆盖率

```text
引用覆盖 93% · 42/45 句
```

- 正文按中英文句号/问号/分号拆成句子；
- 一个条目只要挂了来源链接，就视为该条目正文的句子都有出处；
- 三句话速览是模型综合句，没有逐条链接，按“未直接引用”计入；
- 这是“有没有链接可点”，不是“每个数字是否被独立验证”。

它和「无依据率」互补：前者看引用密度，后者看条目级来源证据。

## 每条断言绑定来源

点开简报页的「每句引用明细」，每条句子会显示：

- **直接**：句子里出现了来源名（例如 TechCrunch），只绑定这个来源；
- **条目级**：句子没有点名来源，继承该条内容的全部链接；
- **无来源**：条目本身没有链接。

这是 claim-to-source 绑定，不是语义相似度模型。它的价值是把“整条内容的链接”拆到句子，
让读者能点回具体来源；局限是“条目级”仍然可能把多个来源都指向同一句话。

## 为什么先这么做

- 可解释：每个数字都能回到底层条目；
- 可重复：同一标题永远得到同一个标签；
- 不烧模型：不需要为每条内容调用 LLM；
- 不装权威：不把启发式叫“事实核查”。

- 来源平衡建议（补哪些类型的源）；
