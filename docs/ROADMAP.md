# Meerkat Roadmap

> 从「AI 日报」走向「个人决策终端」。
>
> 判断标准：每个功能是否让用户在**更短时间内做出更可信的判断**；不以信息量、源数量或功能数量为目标。

## 核心公式

```text
价值 = 相关性 × 新颖性 × 可信度 × 可行动性 / 获取时间
```

Meerkat 已经解决相关性（主题/源/编辑重点）、新颖性（48h + 跨天去重 + no-change）和可信度（来源依据/链接校验/降级可见）。下一阶段补的是**可行动性**与**获取时间**。

## P0：决策层

### 1. 决策笔记（本迭代）

在任意一条简报内容下写一句自己的判断，本地保存：

- 我认为会影响什么；
- 我准备做什么；
- 什么信号出现时说明我判断错了。

为什么：

- 当前产品停在「信息」；没有决策记录，周回顾没有素材，产品也无法证明自己有用。
- 这是和 RSS / newsletter / 通用摘要最直接的差异。

验收：

- 每条内容可以写/改/删判断；
- 判断按条目 id 持久化；
- 刷新、切主题、重启后仍在；
- 有判断的条目在阅读界面可见。

### 2. 周回顾（本迭代）

按最近 7 天聚合：

- 写了哪些判断；
- 对应哪条内容、来源、日期；
- 本周有多少期简报、多少条内容、多少天是 no-change；
- 没有判断的空白状态。

为什么：

- 日报是「输入」，周回顾是「输出」；
- 没有回顾，用户不会记得自己上周判断过什么；
- 这是留存和付费的理由，不是又一个摘要。

### 3. 交付层（下一迭代）

- 每日摘要邮件 / 飞书 / Slack；
- 移动端可读分享页；
- no-change 也能推送；
- 一键转发某条判断/内容。

**已完成（本迭代）**：飞书 / Slack / Discord / 通用 webhook；设置页可配置、发送测试；定时任务完成后自动推送三条速览；no-change 也会推送一句结论。邮件摘要（SMTP）也已接入，密码走系统加密存储。手机阅读（局域网临时链接）已接入：同一 Wi-Fi 扫码/打开，30 分钟后自动失效。

**待做**：单条判断转发、二维码、移动端 PWA。

为什么：用户的早晨不在 Electron 里；只在桌面端等于只在打开 app 时存在。

## P1：记忆层

### 4. 实体与事件

- 公司页、人物页、事件页；
- 融资、产品、裁员、负面；
- 访谈/视频挂到公司/人物；
- 事件时间线与「上周 vs 本周」。

**已完成（本迭代）**：40 个公司/人物实体词表 + 本地倒排；实体页按实体聚合最近内容，展示日期时间线、来源和条数；启动回填历史，日报完成后增量索引。事件层已加入：融资/产品/裁员/监管/安全/研究/合作规则标签，以及最近 7 天 vs 上周的对比。实体支持手动增删/改名/别名，别名变更会重建索引；事件卡可进入独立事件页，页面里有事件级判断，并展示关联条目的决策笔记。事件支持手动合并、拆分、恢复自动事件；事件可一键转为现有 tracking story。事件判断已进入周回顾；事件页的「评论 / 时间线」复用第一条内容的现有 thread。

**待做**：事件判断的编辑入口、事件合并的撤销历史、事件页评论与事件判断放在同一上下文。

为什么：总结会商品化，**纵向记忆 + 实体关系**不会。

### 5. 信任与评估

- 事实 / 推断 / 传闻标记；
- 来源多样性与单源主导警告；
- 固定评测集：无依据断言率、链接准确率、重复率；
- no-change 的可审计解释。

**已完成（本迭代）**：规则化事实/推断/传闻标签；简报页来源多样性 + 最大单源占比；无依据率（没有 trace 来源证据的条目占比）；句子级引用覆盖率；每句引用明细（直接/条目级/无来源）；[docs/TRUST.md](TRUST.md) 说明定义与边界。事件判断可在周回顾里直接编辑/删除；事件合并支持最多 20 步 LIFO 撤销。

**待做**：固定评测集、人工校正、来源平衡建议、真正的语义 claim-source 匹配。

## P2：团队与商业化

### 6. 可选加密同步

本地优先 + 可选云同步，不强制账号；解决换机、移动端和备份。

### 7. 团队空间

共享主题、评论、权限、审计；按团队/席位收费。

### 8. Source pack 市场

把主题 + 源 + 编辑重点做成可分享的包，由创作者/机构维护；这是分发和网络效应。

## 不做

- 无限信息流；
- 用源数量当卖点；
- 通用聊天机器人；
- 独立视频摘要器；
- 没有留存前的社区/社交。

## 验证指标

| 指标 | 含义 |
|---|---|
| 5 分钟完成率 | 打开到关闭是否在 5 分钟内 |
| 决策笔记率 | 每期产生多少条判断 |
| 周回顾回访 | 第二周是否回来看上周判断 |
| no-change 信任 | 空状态后第二天是否回来 |
| 交付打开率 | 邮件/飞书是否进入工作流 |
| 来源包采用率 | 用户是否导入别人的主题配置 |

先找 10 个真实用户做两周 diary study，再决定是否扩功能。
