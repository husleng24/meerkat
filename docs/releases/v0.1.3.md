# Meerkat v0.1.3

macOS 首次可以正常分发了：Developer ID 签名 + Apple 公证。功能上补了事件时间线与持续跟踪、
判断层、视频报告、邮件/Webhook 推送和手机阅读页。

## 下载

| 平台 | 文件 |
|---|---|
| macOS（Apple Silicon） | `Meerkat-0.1.3-arm64.dmg` |
| macOS（Intel） | `Meerkat-0.1.3-x64.dmg` |
| Windows（安装版） | `Meerkat-0.1.3-x64.exe` |
| Windows（便携版） | `Meerkat-0.1.3-portable.exe` |

macOS 两个 dmg 都已签名、公证并 staple，双击即可打开。Windows 仍未签名，SmartScreen 选
「更多信息 → 仍要运行」。

## 新增：事件时间线与跟踪

- 新闻评论里 `@agent` 先分意图：提问 / 整理时间线 / 持续跟踪
- 跟踪页集中管理所有事件，可暂停、继续、放弃
- 时间线卡先给「现在」、节点/报道数和阶段，默认最新在上
- 完整时间线页：全部节点、来源汇总、时间缺口、待确认问题
- 跟踪时自动扩展中英文/换说法别名，并按新报道追加进展
- 连续 3 次没有新进展时主动询问是否继续跟踪

## 新增：判断层

- 把简报里的 claim 绑定到来源，标记覆盖率与信任信号
- 事件页、事件合并/拆分、标签、实体记忆
- 周末回顾与决策笔记

## 新增：视频报告

- 为 YouTube 创作者主题抓取视频字幕，生成完整对话报告并导出 Markdown

## 新增：可选账号

- 自带 Supabase 项目即可启用邮箱注册/登录与 GitHub OAuth
- 本地使用仍然无账号；数据同步留到下一步
- 会话用 safeStorage 存在本机

## 新增：推送与分享

- SMTP 邮件摘要（密码本机加密）
- 飞书 / Slack / Discord Webhook
- 手机阅读：局域网一次性分享页，30 分钟后自动关闭

## 变化

- 升级到 Electron 44
- 全局导航收进侧栏图标 rail；非今日页使用上下文侧栏
- 测试增至 **530**，覆盖时间线、跟踪、判断层、视频、分享与推送
- 更新提示改为紧凑侧栏 badge

## 已知问题

- Windows 安装包未签名，SmartScreen 会提示未知发布者
- Intel dmg 已签名/公证，但未在真实 Intel 机器上启动验证
- 视频报告依赖 YouTube 字幕可用性，部分视频可能没有字幕
- 邮件/Webhook 需要用户自己配置，应用不提供中转服务器

## 安装

- **macOS**：打开 dmg，把 Meerkat 拖进「应用程序」
- **Windows**：安装版或便携版
- 数据位置：macOS `~/Library/Application Support/Meerkat`，Windows `%APPDATA%\Meerkat`
