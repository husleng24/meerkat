# Meerkat v0.1.2

升级提醒变得不打扰，产品的定位也从「AI 简报」扩成「任何领域的变化」。

## 下载

| 平台 | 文件 |
|---|---|
| macOS（Apple Silicon） | `Meerkat-0.1.2-arm64.dmg` |
| macOS（Intel） | `Meerkat-0.1.2-x64.dmg` |
| Windows（安装版） | `Meerkat-0.1.2-x64.exe` |
| Windows（便携版） | `Meerkat-0.1.2-portable.exe` |

## 新增

- **侧栏升级入口**：有新版本时，侧栏底部出现「↓ 新版本 vX · 下载」，不再用整条横幅打断阅读；
  点击直接打开 Release 页（changelog 与安装包都在那里）
- **版本对比与 changelog**：横幅与设置 →「关于」都会显示 `v0.1.1 → v0.1.2`，并能就地展开
  GitHub Release 里的更新说明
- **设置 →「关于」**：显示当前版本、手动检查更新

## 变化

- **定位扩展**：slogan 改为「让你轻松看清任何领域的变化」/「See what changed in any field,
  effortlessly.」；AI 只是默认示例，时装、芯片、政策等领域加好源即可
- **README 重写**：中英双语对齐，新增「Why Meerkat」四条的差异化说明，修正过期的测试数字
- **macOS 打包**：改为 ad-hoc 签名并附带关闭库校验的 entitlements

## 已知问题（重要）

macOS 包**仍未使用 Developer ID 签名/公证**。本机实测（macOS 15.7.9）通过 Finder 双击启动
仍可能被 AMFI 拒绝；目前只适合开发者从终端启动。正常分发给用户需要 Apple Developer 证书。

Windows 安装包正常。

## 安装

- **macOS**：打开 dmg，把 Meerkat 拖进「应用程序」。若无法启动，见上面的已知问题。
- **Windows**：安装版或便携版，SmartScreen 选「更多信息 → 仍要运行」。
- 数据位置不变：macOS `~/Library/Application Support/Meerkat`，Windows `%APPDATA%\Meerkat`。
