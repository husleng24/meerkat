# Meerkat v0.1.0

第一个可安装的版本：每天一份 AI 领域简报，只留真正变了的事。

## 下载

| 平台 | 文件 | 说明 |
|---|---|---|
| macOS（Apple Silicon） | `Meerkat-0.1.0-arm64.dmg` | 拖进「应用程序」 |
| macOS（Intel） | `Meerkat-0.1.0-x64.dmg` | 同上 |
| Windows（安装版） | `Meerkat-0.1.0-x64.exe` | NSIS 安装包，装到用户目录 |
| Windows（便携版） | `Meerkat-0.1.0-portable.exe` | 免安装，双击即用 |

## 这个版本能做什么

- 按「领域 → 主题」组织信息；每个主题有自己的源、排程和简报
- 每天定时采集 + 成稿，48 小时窗口，打分去重后由模型写成简报
- 「和昨天比」：新增 / 有进展 / 没再提
- 全文检索、时间线、已读收藏
- 源健康度与按主题推荐源
- 领域汇总：把同一领域各主题的简报合成一份综述
- AI 对话：基于当天简报提问、总结，可切换供应商
- 导出 Markdown / HTML / PDF / 富文本

## 安装说明（重要）

这两个包都**没有代码签名**（个人项目，未购买证书）：

- **macOS**：首次打开会被 Gatekeeper 拦下。右键点 App → 打开，或执行
  `xattr -dr com.apple.quarantine /Applications/Meerkat.app`。
- **Windows**：SmartScreen 可能提示"未知发布者"，点「更多信息 → 仍要运行」。

## 首次启动

选几个领域 → 自动建主题并挂上默认源 → 立即采集一次（约 1–2 分钟）。
不接模型也能用，简报会降级为"仅聚合"版。

## 已知限制

- 本版本没有自动更新，需要手动下载新版本
- AI 对话非流式；重排功能在后续版本
- 领域汇总依赖各主题当天的简报
