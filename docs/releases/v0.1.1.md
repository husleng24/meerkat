# Meerkat v0.1.1

第一个带**升级提醒**的版本，也是仓库改为公开后的第一个版本。

## 下载

| 平台 | 文件 |
|---|---|
| macOS（Apple Silicon） | `Meerkat-0.1.1-arm64.dmg` |
| macOS（Intel） | `Meerkat-0.1.1-x64.dmg` |
| Windows（安装版） | `Meerkat-0.1.1-x64.exe` |
| Windows（便携版） | `Meerkat-0.1.1-portable.exe` |

## 新增

- **升级提醒**：启动时查询 GitHub 最新 Release（24 小时内最多一次），有新版本时在顶部显示提示并弹通知；
  设置 →「关于」可以手动检查，点「下载更新」跳到对应 Release。只提示、不自动下载（安装包未签名）。
  自动更新从「下一个版本」开始才能收到提醒，v0.1.1 本身是第一个具备该能力的版本。
- **MIT License**：仓库正式以 MIT 授权。
- **中英双语文档**：README.md（English）与 README.zh-CN.md（简体中文），两篇可互相切换。
- **发版流程文档**：[docs/RELEASE.md](../RELEASE.md)。

## 修复

- 点击条目里的外链不再把应用窗口导航走（改为系统浏览器打开）。

## 安装说明（重要）

两个平台都**没有代码签名**：

- **macOS**：首次打开被 Gatekeeper 拦下时，右键点 App → 打开，或执行
  `xattr -dr com.apple.quarantine /Applications/Meerkat.app`。
- **Windows**：SmartScreen 提示"未知发布者"时，点「更多信息 → 仍要运行」。

## 已知限制

- 没有自动更新（只提示，需手动下载安装）
- AI 对话非流式；重排功能在后续版本
- 领域汇总依赖各主题当天的简报
