# 五种形态原型

同一份 23 条内容、同一套字号与配色，只换版式。全部是 1180×820 的静态渲染，没有交互。

打开 `index.html` 逐个看；`00-contact.png` 是五张并排的总览。

| 文件 | 形态 | 一屏条数 | 它赌什么 |
|---|---|---|---|
| `01-cards.html` | 卡片流 | 3 | 值得为解读牺牲密度 |
| `02-list.html` | 紧凑列表 | 19 | 标题本身够判断要不要读 |
| `03-mosaic.html` | 头版网格 | 23（全部） | 面积能表达重要性 |
| `04-columns.html` | 分栏并置 | 23（七列并排） | 横向比较真的会发生 |
| `05-timeline.html` | 时间河流 | 23（三组） | 时间轴比板块轴更有信息量 |

数据来自 2026-11-01 的真实简报（7 个板块 / 23 条）。日期分布 10-30:9、10-31:10、11-01:4 —— 这是时间河流那条最先露出的破绽。
